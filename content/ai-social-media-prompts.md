## PROMPT 1 — Hook Library
**When to use:** Before a content sprint. Run once, save the output. Pull hooks for weeks.

```
I'm an Instagram creator in the vacation rental / short-term rental niche.
I run Indigo Palm Collective — a collection of 4 design-forward desert properties
in Palm Springs, Indio, and the Coachella Valley.

Generate 100 viral hooks:

Categories:
- Questions (make them stop and think)
- Statements (bold claims that challenge)
- Numbers (specific lists that get saves)
- Stories (open loops that pull them in)
- Controversial (takes that spark debate)
- Relatable (things your audience feels)

Each hook should be under 15 words.
Each should make someone want to read more.

Niche context: desert travel, luxury vacation rentals, Airbnb hosting,
Coachella/Stagecoach/BNP Paribas events, Palm Springs lifestyle, boho/modern desert design.
```

## PROMPT 2 — Caption Writer
**When to use:** Batching a week or month of posts. Swap `[TOPIC/BRAND]` for a specific campaign.

```
Write 20 Instagram captions for Indigo Palm Collective — a boutique vacation rental
brand with 4 desert properties in the Coachella Valley (Palm Springs, Indio, Cochran area).

For each:
- Hook (first line that stops scrolling)
- Body (2-4 paragraphs)
- Hashtags (10-15 mixed size)
- Call to action

Formats to include:
- Educational posts (value — hosting tips, travel hacks, desert packing lists)
- Personal stories (relatable — behind the scenes building/designing the properties)
- How-to tutorials (useful — how to book direct, how to find the best Coachella rentals)
- Opinion pieces (provocative — why Airbnb is screwing travelers, why direct booking wins)
- Product/service promos (selling — book Terra Luz, Sundune, Cozy Cactus, The Well)

Write like a human. Not a brand.
Voice: warm, knowledgeable, slightly irreverent. A host who actually lives this.
```

## PROMPT 3 — Reel Script Generator
**When to use:** Planning a filming day. Run this, pick 2-3 scripts, batch shoot in one afternoon.

```
I want to create a Reel about [TOPIC — e.g. "why we built Terra Luz in Indio" /
"what $300/night gets you in Palm Springs vs Coachella Valley" / "how to find
vacation rentals near BNP Paribas Open" / "Coachella 2027 rental guide"].

Generate 10 Reel scripts:

For each:
- Hook (first 3 seconds — make them watch)
- What to say (word for word)
- B-roll suggestions (what to show — our properties are in desert settings,
  pool shots, interior design, Coachella Valley landscapes)
- Text overlays to add
- Ending CTA (follow / save / share / book at indigopalm.co)
- Length (15 sec / 30 sec / 60 sec)

Make them engaging from second one.
No boring intros. No slow builds.
Niche: desert travel, vacation rentals, Coachella Valley, STR hosting.
```

**Top Reel topics to cycle through:**
- Property reveals / before & after
- "What $X/night gets you in Palm Springs"
- Coachella / Stagecoach / BNP Paribas event rental guides
- Design process / why we chose each piece
- Direct booking vs Airbnb
- Desert travel tips (packing, heat, day trips)
- Behind the scenes: hosting struggles / wins

## PROMPT 4 — Carousel Structure Builder
**When to use:** Creating save-worthy educational content. Carousels get 3x more saves than single images.

```
Create 15 carousel posts about [TOPIC — e.g. "how to find the best Coachella Valley
vacation rental" / "Palm Springs travel guide" / "why you should book direct" /
"desert house design tips"].

For each:
Slide 1: Hook (stop scroll)
Slides 2-8: Value content
Slide 9: Summary or key takeaway
Slide 10: CTA (follow / save / comment / book at indigopalm.co)

For each slide:
- What to write
- What visual to use (we have desert property photos, pool shots, interior design,
  Coachella Valley landscapes)
- How long to stay (7-10 seconds)

Format that gets saves: Lists, tips, step-by-step guides.
Brand voice: knowledgeable desert host, not corporate. Warm, specific, real.
```

**High-save carousel ideas for our niche:**
- "10 things nobody tells you about Coachella Valley vacation rentals"
- "How to book a Palm Springs house direct (and save $200+)"
- "The best areas to stay near Coachella: ranked"
- "Our design rules for a 5-star rental property"
- "Packing list for a desert festival weekend"

## PROMPT 5 — Hashtag Strategy System
**When to use:** Set this up once per quarter. Refresh when engagement drops.

```
I'm an Instagram creator in the vacation rental / desert travel niche.
My account: Indigo Palm Collective (@[handle]) — boutique STR properties
in Palm Springs, Indio, and Coachella Valley CA.

Create a hashtag strategy:

FOR EACH POST:
- 2-3 large hashtags (1M+ posts) — for discovery
- 3-5 medium hashtags (100K-1M posts) — for reach
- 5-7 small hashtags (10K-100K posts) — for niche
- 3-5 micro hashtags (under 10K) — for community

ALSO INCLUDE:
- 10 branded hashtags to create for Indigo Palm Collective
- Hashtag rules (when to use more/fewer)
- What to avoid (banned or saturated hashtags)

Research which hashtags are growing right now in these areas:
palm springs travel, coachella valley vacation rentals, desert airbnb,
short term rental hosting, boho desert design, coachella festival travel.
```

## PROMPT 6 — Engagement Growth System
**When to use:** When ready to seriously grow. This one requires daily follow-through.

```

in [TIMEFRAME — e.g. 90 days].

Account: Indigo Palm Collective — vacation rental brand, desert travel content,
Coachella Valley properties. Target audience: travelers aged 25-45 planning
trips to Palm Springs / Coachella / Stagecoach / BNP Paribas. Secondary:
Airbnb hosts interested in STR design and hosting strategy.

Create a system that runs on autopilot:

DAILY TASKS:
- Comment strategy (on which accounts — travel, desert lifestyle, Coachella,
  festival content, vacation rental, interior design)
- DM strategy (templates that feel personal, not spammy)
- Story strategy (what to post daily to stay top of mind)
- Reply strategy (how to respond to comments to boost reach)

ENGAGEMENT HACKS:
- How to get 10x more engagement on our niche content
- When to post for maximum reach (time zones: LA, NYC, Chicago — our main markets)
- How to turn followers into email subscribers (we have a direct booking site: indigopalm.co)
- Funnel to turn followers into direct bookers (bypassing Airbnb)

Build a system that works while you sleep.
End goal: every follower should know indigopalm.co exists and how to book direct.
```
