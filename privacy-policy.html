Privacy Policy for Desert Edit Dashboard

Last Updated: July 11, 2026

Overview

Desert Edit Dashboard ("the App") is a private tool that connects to QuickBooks Online via OAuth on behalf of Indigo Palm Collective. This app is used exclusively by Indigo Palm Collective business and is not available to the public. It currently handles authorization only; there is no automated financial data sync yet.

Information We Collect

Authentication Data

When you authorize this app to connect to your QuickBooks Online account, we receive:

  • A one-time OAuth authorization code
  • QuickBooks Company ID (Realm ID)

This information is used for a manual, one-time token exchange to establish the connection. No financial transactions, bank balances, or vendor/customer data are currently collected or synced by this app.

How We Use Your Information

The authorization code and Company ID are used solely to complete the QuickBooks OAuth handshake. Future versions of this app may add automated financial reporting; this policy will be updated before that happens.

Data Storage

The app currently connects to QuickBooks Online for authorization only. The OAuth authorization code and Company ID (Realm ID) are logged server-side on our Cloudflare Worker for a one-time, manual token exchange; they are not written to any response returned to the browser. There is no automated sync of financial data at this time.

  • No data is shared with third parties
  • No data is sold or used for advertising

Data Security

  • All connections use HTTPS encryption
  • The OAuth callback endpoint requires an admin key to view the authorization code needed for the token exchange
  • Access tokens automatically refresh and expire according to QuickBooks standards

Your Rights

As the sole user of this private app, you can:

  • Disconnect QuickBooks at any time through the Settings page
  • Request deletion of all stored data
  • Revoke app access through your QuickBooks company settings

Data Retention

  • Worker logs containing the authorization code are retained only as long as Cloudflare's standard log retention window
  • No QuickBooks financial data is currently stored by this app

Third-Party Services

This app uses:

  • QuickBooks Online API (Intuit Inc.) - OAuth authorization
  • Cloudflare Workers (Cloudflare Inc.) - Hosting the OAuth callback endpoint

Each service has its own privacy policy:

  • QuickBooks: https://www.intuit.com/privacy/
  • Cloudflare: https://www.cloudflare.com/privacypolicy/
